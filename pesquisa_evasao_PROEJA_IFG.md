## 2. Padrões e Causas de Evasão Identificados na Literatura

### 2.1 Categorias Principais (Revisão Integrativa — Oliveira & Carmo, 2021)

Duas grandes categorias emergem da literatura sobre evasão no PROEJA:

**Categoria 1 — Trabalho / Remuneração / Benefícios**
- Incompatibilidade entre horário das aulas e trabalho (27,9% dos casos — INEP)
- Necessidade de trabalhar para sustento familiar
- Cansaço físico após jornada de trabalho
- Trabalho informal e precarizado

**Categoria 2 — Formação e Prática Docente**
- Falta de preparo dos professores para lidar com a modalidade EJA
- Metodologias tradicionais ("bancárias") incompatíveis com o perfil do aluno
- Currículos rígidos e descontextualizados

### 2.2 Fatores Específicos do PROEJA no IFG Goiânia (Castro & Vitorette, 2016; Pereira, 2011)

| Fator | Descrição |
|-------|-----------|
| **Resistência institucional** | Apenas a Coordenação de Turismo e Hospitalidade aderiu ao PROEJA inicialmente |
| **Focalização vs. universalização** | Programa tratado como ação focalizada, não como política institucional permanente |
| **Evasão elevada** | Cursos Técnicos em Serviços de Alimentação e Cozinha com altos índices de abandono |
| **Perfil socioeconômico** | Alunos trabalhadores, baixa renda, majoritariamente pretos e pardos (76,8% na EJA) |
| **Jornada dupla** | Trabalho durante o dia + aula à noite → cansaço e abandono |
| **Metodologia inadequada** | Falta de adaptação curricular para a realidade dos alunos |

### 2.4 Diferenças de Gênero

Pesquisas apontam diferenças significativas nos motivos de evasão entre homens e mulheres:
- **Homens**: trabalho, desinteresse
- **Mulheres**: responsabilidades familiares, cuidado com filhos, gravidez

## 3. Propostas de Medidas para Redução da Evasão

### 3.1 Medidas Institucionais (IFG Goiânia)

1. **Flexibilização curricular** — Adequação do calendário e horários à realidade do aluno trabalhador
2. **Formação docente continuada** — Capacitação específica para atuação na EJA
3. **Metodologias ativas e contextualizadas** — Abordagem freireana, valorização dos saberes prévios
4. **Acompanhamento tutorial** — Monitoramento individualizado dos alunos com risco de evasão
5. **Assistência estudantil** — Fortalecimento de bolsas, auxílio transporte, alimentação e moradia

### 3.2 Medidas Pedagógicas

6. **Currículo integrado** — Articulação entre formação técnica e básica de forma significativa
7. **Avaliação formativa** — Processos avaliativos compatíveis com o perfil do estudante
8. **Aulas práticas e laboratoriais** — Maior engajamento com atividades "mão na massa"

### 3.3 Medidas de Apoio ao Estudante

9. **Programa de acolhimento** — Integração dos novos alunos com a comunidade acadêmica
10. **Escuta ativa** — Pesquisas regulares de satisfação e identificação precoce de riscos
11. **Horário flexível / EAD híbrido** — Possibilidade de atividades remotas complementares
12. **Creche ou auxílio-creche** — Suporte para alunos com filhos pequenos

### 3.4 Medidas Preditivas (Baseadas em Dados)

13. **Sistema de alerta precoce** — Identificação de alunos em risco com base em frequência, notas e perfil
14. **Dashboard de monitoramento** — Acompanhamento visual em tempo real dos indicadores

## 4. Proposta de Dashboard para Análise de Evasão

### 4.1 Dados Necessários

Para alimentar o dashboard, sugere-se estruturar os dados em ao menos 3 tabelas:

| Tabela | Campos Sugeridos |
|--------|------------------|
| **Alunos** | ID, nome, idade (faixa etária), sexo, raça/cor, renda familiar, bairro/região, trabalha (S/N), turno |
| **Matrículas** | ID matrícula, ID aluno, curso, semestre ingresso, semestre evasão, status (ativo/evadido/formado) |
| **Frequência** | ID matrícula, mês, % presença, % faltas |
| **Motivo Evasão** | ID matrícula, motivo (entrevista de desligamento), data |

### 4.2 Indicadores-Chave (KPIs)

| KPI | Descrição |
|-----|-----------|
| **Taxa de Evasão Geral** | % de alunos evadidos / total de matrículas |
| **Taxa por Curso** | Evasão segmentada por curso técnico |
| **Taxa por Período** | Evolução histórica semestral |
| **Taxa por Perfil** | Evasão por faixa etária, sexo, raça, renda |
| **Tempo Médio até Evasão** | Média de meses cursados antes do abandono |
| **Taxa de Retenção** | % de alunos que permanecem após 1º ano |
| **Principais Motivos** | Ranking de causas de evasão |

### 4.5 Modelo Lógico do Banco de Dados

```sql
-- Tabela de alunos
CREATE TABLE alunos (
    id_aluno INT PRIMARY KEY,
    nome VARCHAR(200),
    data_nascimento DATE,
    sexo CHAR(1),
    raca_cor VARCHAR(50),
    renda_familiar DECIMAL(10,2),
    trabalha BOOLEAN,
    bairro VARCHAR(100),
    possui_filhos BOOLEAN,
    escolaridade_anterior VARCHAR(100)
);

-- Tabela de cursos
CREATE TABLE cursos (
    id_curso INT PRIMARY KEY,
    nome_curso VARCHAR(200),
    modalidade VARCHAR(50), -- PROEJA, EJA, EJA-TEC
    turno VARCHAR(20),
    carga_horaria INT
);

-- Tabela de matrículas
CREATE TABLE matriculas (
    id_matricula INT PRIMARY KEY,
    id_aluno INT REFERENCES alunos(id_aluno),
    id_curso INT REFERENCES cursos(id_curso),
    semestre_ingresso VARCHAR(6), -- ex: 2024.1
    semestre_evasao VARCHAR(6),
    status VARCHAR(20), -- ativo, evadido, formado, transferido
    motivo_evasao TEXT,
    id_motivo_categoria INT
);

-- Tabela de categorias de motivo
CREATE TABLE motivos_evasao (
    id_motivo INT PRIMARY KEY,
    categoria VARCHAR(100), -- Trabalho, Pessoal, Saúde, Currículo, etc.
    descricao TEXT
);

-- Tabela de frequência mensal
CREATE TABLE frequencia (
    id_matricula INT REFERENCES matriculas(id_matricula),
    mes DATE,
    presencas INT,
    faltas INT,
    total_aulas INT,
    PRIMARY KEY (id_matricula, mes)
);
```
