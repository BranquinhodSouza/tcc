6. Fluxo de Autenticação (Sequência)

sequenceDiagram participant U as Usuário (Mobile) participant APP as React Native App participant API as FastAPI Backend participant DB as PostgreSQL U->>APP: Acessa o app APP->>API: POST /auth/login {email, password} API->>DB: SELECT * FROM users WHERE email = ? DB-->>API: Dados do usuário API->>API: Verificar password com bcrypt API->>API: Gerar token JWT API-->>APP: {token, user} APP->>APP: Armazenar token no secure storage APP-->>U: Tela principal

7. Fluxo de Recomendação (Sequência)

sequenceDiagram participant U as Usuário participant APP as Mobile App participant API as Backend participant DB as PostgreSQL U->>APP: Acessa tela de recomendações APP->>API: GET /recommendations {token} API->>API: Decodificar token JWT API->>DB: SELECT preferências do usuário DB-->>API: skin_type, skin_tone, product_types, etc. API->>DB: SELECT produtos com JOINs WHERE correspondem às preferências DB-->>API: Lista de produtos API->>API: Calcular relevance_score para cada produto API-->>APP: {products, total} APP->>APP: Renderizar lista de produtos APP-->>U: Lista de recomendações

8. Fluxo de Avaliação (Sequência)

sequenceDiagram participant U as Usuário participant APP as Mobile App participant API as Backend participant DB as PostgreSQL U->>APP: Seleciona produto APP->>API: GET /products/{id} API-->>APP: Detalhes do produto APP-->>U: Tela de detalhes U->>APP: Avalia produto (nota + comentário) APP->>API: POST /feedbacks {product_id, rating, comment} API->>DB: INSERT INTO feedbacks DB-->>API: Confirmação API-->>APP: {success: true} APP-->>U: Confirmação visual
